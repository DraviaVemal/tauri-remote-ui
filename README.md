# tauri-remote-ui  (AGPL-3.0)

**Tauri Remote UI** is a plugin that allows you to expose your Tauri application's UI to any web browser.
[![Crates.io Version](https://img.shields.io/crates/v/tauri-remote-ui?style=flat&label=crates.io%20%3A%20tauri-remote-ui)](https://crates.io/crates/tauri-remote-ui) [![NPM Version](https://img.shields.io/npm/v/tauri-remote-ui?label=npm%20%3A%20tauri-remote-ui)](https://www.npmjs.com/package/tauri-remote-ui) [![License](https://img.shields.io/badge/license-AGPL--3.0-green.svg)](LICENSE)

## 📖 [Documents](https://docs.draviavemal.com)

Refer document central for detailed information [docs](https://docs.draviavemal.com)

## 📦 Installation

```sh
npm install tauri-remote-ui
```

The `npm:` alias keeps imports unscoped (`import { invoke } from "tauri-remote-ui/api/core"`).
